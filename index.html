Beam On!

  • Build bunkers
  • Plan treatments
  • Run daily QA
  • Treat patients

A management game set in a hospital radiotherapy department, built to show the many roles of the clinical medical physicist.

  • Build the patient pathway: consult clinic, CT simulator, planning room, physics office, linac bunkers and an HDR brachytherapy suite.
  • Hire oncologists, medical physicists and radiation therapists, and keep the queues moving.
  • Your physicists plan and check every treatment, commission the linacs, run daily QA, fix faults and exchange the Ir-192 source.
  • Make the physics calls in 20 scenarios drawn from real professional guidance, each with consequences and an explanation.
