# Beam On!

A Theme Hospital-inspired browser game about running a radiotherapy department, built to show the many roles of the clinical medical physicist.

**Home page:** https://hafizmz.github.io/beam-on/

**Play it:** https://hafizmz.github.io/beam-on/play/

**Beam On: First Light**, a six-chapter story game for secondary school students: https://hafizmz.github.io/beam-on/first-light/

**Beam On! Junior**, mini-games about hospital machines for kindergarten and primary: https://hafizmz.github.io/beam-on/junior/

**Beam On! Explorace**, a stereotactic radiotherapy race for science camp teams (English and BM): https://hafizmz.github.io/beam-on/race/ (demo: `race/demo/`)
- **Beam On! Explorace Quick**, a shorter three-station version (introduction, CT sim, treatment): https://hafizmz.github.io/beam-on/race/quick/ (demo: `race/quick/demo/`)

## Files

- `index.html`: home page linking all the games
- `play/index.html`: Beam On!
- `first-light/`: Beam On: First Light
- `junior/index.html`: Beam On! Junior
- `race/index.html`: Beam On! Explorace, run on one shared device per station. Teams and the leaderboard are kept in that device's browser; staff change the default PIN under Staff settings. `race/quick/` is the three-station quick race built from the same source.
- `qr.svg`: QR code for the home page

## What you do

- Build the patient pathway: consult clinic, CT simulator, planning room, physics office, linac bunkers and an HDR brachytherapy suite.
- Hire oncologists, medical physicists and radiation therapists, and keep the queues moving.
- Your medical physicists plan every treatment, check every plan, commission the linacs, run daily QA, fix machine faults, exchange the Ir-192 source and run HDR treatments.
- Make the physics calls: 20 scenarios drawn from TG-142, TG-218, TG-114, TRS-398, TRS-483, NCRP 151, ICRP 103 and IAEA dosimetry audits, each with consequences and an explanation.

## Notes

This is an original educational game inspired by the mechanics of management sims. It uses no assets from any commercial game. Tolerances and explanations are for teaching; always follow your own department's protocols.

Progress is saved in the player's own browser.
