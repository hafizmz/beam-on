# Beam On!

A Theme Hospital-inspired browser game about running a radiotherapy department, built to show the many roles of the clinical medical physicist.

**Play it:** https://hafizmz.github.io/beam-on/

## What you do

- Build the patient pathway: consult clinic, CT simulator, planning room, physics office, linac bunkers and an HDR brachytherapy suite.
- Hire oncologists, medical physicists and radiation therapists, and keep the queues moving.
- Your medical physicists plan every treatment, check every plan, commission the linacs, run daily QA, fix machine faults, exchange the Ir-192 source and run HDR treatments.
- Make the physics calls: 20 scenarios drawn from TG-142, TG-218, TG-114, TRS-398, TRS-483, NCRP 151, ICRP 103 and IAEA dosimetry audits, each with consequences and an explanation.

## Notes

This is an original educational game inspired by the mechanics of management sims. It uses no assets from any commercial game. Tolerances and explanations are for teaching; always follow your own department's protocols.

Progress is saved in the player's own browser.
